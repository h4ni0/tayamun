# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Report it privately through [GitHub Security Advisories](https://github.com/h4ni0/tayamun/security/advisories/new). Include the affected version, reproduction steps, impact, and any suggested mitigation.

You should receive an acknowledgement within seven days. Confirmed issues will be investigated and fixed before public disclosure whenever possible.

## Supported versions

Security fixes are provided for the latest published version of Tayamun.
