# تصريحات الأذونات والبيانات

## الغرض الوحيد

تحسين اتجاه عرض النص العربي المختلط على صفحات الويب من دون تعديل محتوى الصفحة أو إعادة ترتيب تخطيطها.

## تبرير الأذونات

### الوصول إلى المواقع (`http://*/*` و`https://*/*`)

يلزم لفحص النص الظاهر والحقول النصية، ثم تطبيق اتجاه العرض والخيارات التي اختارها المستخدم على الكتلة النصية المتأثرة. لا تعمل الإضافة في صفحات المتصفح الداخلية، ولا ترسل محتوى المواقع إلى أي مكان.

### التخزين (`storage`)

يلزم لحفظ ثلاثة تفضيلات محلية لكل اسم مضيف دقيق: تشغيل تَيَامُن، والمحاذاة إلى اليمين، واستخدام خط Tajawal. لا تُستخدم المزامنة.

### موارد الويب (`fonts/*.woff2` و`shadow-main-world.js`)

تُتاح ملفات Tajawal المضمّنة لبرنامج المحتوى حتى يطبقها محليًا عند تشغيل خيار تحسين الخط. ويُستخدم الجسر المحلي الصغير `shadow-main-world.js` فقط لاكتشاف إنشاء Shadow DOM مفتوح لحظيًا بدل إجراء مسح دوري للصفحة. جميع هذه الموارد مضمنة في الإضافة، ولا تنزّل شيفرة أو ترسل بيانات أو تتصل بالشبكة.

## صفحة ممارسات الخصوصية في Chrome

- **هل تُستخدم شيفرة بعيدة؟** لا.
- **هل تجمع الإضافة بيانات مستخدم؟** لا.
- **هل تبيع البيانات أو تستخدمها للإقراض أو الإعلانات؟** لا.
- **هل تنقل البيانات خارج الجهاز؟** لا.
- **هل يقتصر الاستخدام على الغرض الوحيد المعلن؟** نعم.
- **هل تُستخدم البيانات لأغراض لا ترتبط بالوظيفة؟** لا.

## تصريح Firefox

يجب أن يحتوي بيان Firefox على:

```json
"data_collection_permissions": {
  "required": ["none"]
}
```

تعني `none` أن الإضافة لا تجمع بيانات ولا تنقلها خارج الإضافة أو المتصفح المحلي.
