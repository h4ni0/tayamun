# ملاحظات المراجعة وإعادة البناء

## ملاحظات للمراجع

- الوظيفة الوحيدة هي ضبط اتجاه عرض كتل النص التي يبدأ أول حرف Unicode فيها بحرف عربي قياسي.
- لا تُعاد كتابة النصوص، ولا تُلف بعناصر، ولا تُضاف إليها علامات ثنائية الاتجاه.
- لا توجد طلبات شبكة أو تحليلات أو شيفرة بعيدة.
- يرقّع الجسر المحلي المضمّن `shadow-main-world.js` الدالة `attachShadow` مؤقتًا لإشعار برنامج المحتوى عند إنشاء Shadow DOM مفتوح، ثم يعيد الأصل عند إنهاء السياق؛ ولا يقرأ بيانات الصفحة أو يرسلها.
- يفحص برنامج المحتوى النص محليًا ويستثني الشيفرة ومحرراتها وكلمات المرور والبريد الإلكتروني وعناوين المواقع والحقول غير النصية.
- تُحفظ الإعدادات محليًا تحت اسم المضيف الدقيق.
- ملفات Tajawal الستة وملف `OFL.txt` مضمنة في الحزمة.

## إعادة بناء حزمة Firefox من المصدر

الحزمة مبنية من TypeScript بواسطة WXT، لذلك يجب إرفاق أرشيف المصدر الذي ينتجه خيار `--sources` مع كل إصدار Firefox.

بيئة البناء التي تم التحقق بها أثناء التطوير:

- Linux x86_64
- Node.js 24.16.0
- npm 11.16.0

من جذر أرشيف المصدر:

```sh
npm ci
npm run check
npm run zip:firefox
```

ينشئ الأمر الأخير حزمة Firefox وأرشيف المصدر تحت `.output/`. يتصل `npm ci` بسجل npm العام لتنزيل الاعتماديات؛ وبعد تثبيتها لا يحتاج البناء إلى شبكة أو متغيرات بيئة أو مفاتيح أو خدمات خارجية. لا توجد خطوات توليد خاصة أو أدوات مغلقة المصدر.

يجب أن يحتوي أرشيف المصدر النهائي على `package-lock.json` الملتزم بالإصدار نفسه. لا تستخدم `npm install` بدل `npm ci` في بناء المراجعة.
